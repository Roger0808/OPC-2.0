# 云端客户端实现边界

## 启动与传输

原生启动仍使用 Wails 2.12.0，独立 Go module 不引用根目录的 `internal/container`、业务 `handler`、Gin、GORM 或 SQLite。应用先验证目标域名、启动 `127.0.0.1:0` 监听，再启动窗口，无固定等待时间。退出关闭转发器、空闲连接和已升级的 WebSocket 连接。

Wails AssetServer 只提供随包携带的前端和本地生成的 `/config.js`。不转发业务 API；Windows AssetServer 的响应缓冲不会影响 SSE。`client-entry.ts` 在动态导入原生复制的 `main.ts` 之前准备运行配置、恢复系统凭据并安装存储/传输适配器，避免 axios 与 stores 在配置之前初始化。

运行时明确区分：

| 地址 | 用途 |
| --- | --- |
| `publicOrigin` | 对外链接、邀请、Embed、CLI、浏览器扩展配对和 MCP OAuth 回调 |
| `transportBase` | 本次启动的随机 loopback HTTP origin；拼接完整 `/api/v1/...` 等路径 |
| Wails 页面来源 | Mac `wails://wails`；Windows 本地 WebView 来源；仅加载客户端资产和原生桥接 |

axios 只接受所选服务端的业务路径。原生复制的 raw fetch 通过受控适配器改写对应 API/文件路径，保留信号、请求体、JWT/Embed token 与租户头；外部资源请求不获得本机能力，明确拒绝向其他地址发送客户端凭据。WebSocket 请求转到真实 HTTP 转发器，用本机能力保护握手，并保留服务端签发的 ticket。

转发器固定连接所选服务器、重设远端 Host 和 Origin，去掉本机能力、Cookie 和 Referer。CORS 来源采用精确名单，`null` 来源也必须持有不可猜测的每进程能力。客户端不保存或使用服务端浏览器 Cookie。传输沿用系统证书验证，不全局跳过 TLS 验证。跨服务器/协议或业务路径外的下载重定向被拒绝。

## 状态与登录

账号密码登录和刷新直接使用现有 API 契约。原生 Lite 自动登录入口不存在，前端路由也显式跳过 auto-setup。`weknora_lite_mode` 不可在此客户端写成 true。部署能力仍向服务端查询，与本机是否使用 Wails 无关。

复制前端现有同步 localStorage token 读取点通过适配器统一看到内存会话；原生桥接在系统安全存储持久化 access/refresh token。连续 token 更新按微任务合并，原生保存串行，下载前等待写入完成。Mac 使用 Security.framework Generic Password；Windows 使用用户绑定 DPAPI 后原子替换密文文件。保存失败保留当前会话内存并提示，不创建明文后备文件；退出标记防止旧系统凭据被恢复。

普通 WebView 配置按服务端哈希前缀隔离，原有按用户 ID 的主题/字体偏好继续生效。修改地址只在下次启动应用，原生会话和请求不能在同一进程内跳到新服务器。账号退出和空间切换推进作用域代数，迟到的 axios/图片/产物响应不能回填旧作用域；成功 Blob 缓存会清空并撤销对象 URL。

刷新失败的处理区分：401/403 或明确无效登录结果清除凭据；临时断网、502、服务异常保留会话，让用户重试。保持原生已有的刷新请求去重。不增加泛化的业务 POST 自动重试。聊天停止仍使用已有业务 stop API，关闭转发连接不替代业务停止命令。

## 文件与本机能力

保留 `/files`、知识库 files、消息 files、Embed files 四条原生鉴权路径。原生下载绑定只接受固定服务器的业务资源路径，租户权限仍由服务器校验；保存地址必须通过系统对话框选择。原生下载流写临时文件，完成后原子替换目标，不在 WebView 中缓存整个大文件。已生成的小文件最多 64 MiB，通过原生保存。HTML 文件预览沿用不含 allow-same-origin 的 sandbox。

批量 ZIP 下载使用已有批量接口的 POST body，通过原生流式保存；原生 POST 下载仅允许该专用路径，保留取消信号，不增加任意 POST 转发或自动重试。单文档、聊天产物和 FAQ 导出也有独立流式路径。客户端生成的小型本地文件仍有 64 MiB 保存上限。

客户端未提供本机 shell、工作目录远程读取、本机 MCP 服务或本机 Ollama 转发。相关业务操作由云端后端/远程沙箱承担；本机目录选择在本客户端明确不可用。浏览器扩展沿用现有云端配对/桥接协议，不把随机本机转发端口写入外部扩展。

MCP OAuth 是现有服务端服务授权，使用公开回调地址与 authorization_attempt 轮询，系统浏览器返回 null 不会立即中止；轮询有超时并在关闭组件时结束。企业微信网页登录回桌面的 SSO 则需要单独的一次性授权交换协议，用户已指定留到下一步，不增加或部署服务端接口。

系统提示词模板来自服务端 `/tenants/kv/prompt-templates`。客户端兼容旧服务端返回的 WeKnora 品牌文案，展示/应用时替换为 OPC；代码片段、路径、模板变量、ID 与技术标识不改。若正文发生品牌适配，保存智能体时保留 OPC 正文，避免空正文加模板 ID 在旧服务端重新解析为旧品牌。服务端已经返回 OPC 正文时，继续沿用原生的模板引用与更新机制。用户已有的自定义提示词不自动批量替换。
